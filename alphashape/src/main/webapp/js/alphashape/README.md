#Geometry JavaScript library

This is the API documentation for the Geometry JavaScript library project.
The project contains the following namespaces:

##alphashape.util
Various utility functions concerning arrays and comparsions, ... 

##alphashape.geom
Geometric data types

##alphashape.ds
Data structures

+ Doubly Connected Edge List
+ AVL Tree

##alphashape.algo

Algorithms

+ Compute convex hull
+ Compute farthest point Voronoi diagram using Skyum's algorithm
+ Closest point Voronoi diagram using Fortune's algorithm
+ Voronoi diagram evaluation and Delaunay graph
+ Alpha Shape and Hull
