# alpha-shapes

This repository contains my bachelor's thesis, "Alpha Shapes - An HTML5 Application for Different Platforms", and the project I created therefore. The thesis is written in German but the project is in English. I wrote the thesis back in 2013, when HTML5 and its usage for creating applications for multiple platforms  was still a new thing. The project is a web application that calculates alpha shapes, Voronoi diagram and the Delaunay graph for a given set of points. It is written in JavaScript and uses the HTML5 canvas element for rendering.

As I am into clean code, I documented the code using JsDoc with type annotations. I used the [Google Closure Compiler](https://developers.google.com/closure/compiler/) to check the code for errors and to minify it. There are unit tests included that use the [Jasmine](https://jasmine.github.io/) testing framework.
